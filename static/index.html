      Berkas & sinkron

      Folder sinkron dua arah
      ~/LinkDeck-Sinkron di PC ⇄ ~/LinkDeck-Sinkron di Debian Belum ada sinkron.

      Mode TV

      Satu klik: layar besar, langsung penuh di TV, suara ikut.

      1. Colok TV ke laptop (HDMI) dan atur sebagai layar tambahan.
      2. Pilih TV di Layar tujuan. Kalau daftarnya kosong, izinkan pengelolaan jendela saat browser bertanya.

      Sambungkan perangkat

      Untuk layar Android, aplikasi, kamera, Mode Game, notifikasi, dan clipboard HP. Memakai adb (Debugging USB/nirkabel).

      1. Di HP buka Setelan → Opsi pengembang, aktifkan Debugging USB.
      2. Colok kabel data ke laptop. Pilih Izinkan saat HP bertanya.
      3. HP langsung muncul di kartu Android.

      Tanpa kabel: pindai kode QR (Android 11+)

      1. HP dan laptop di Wi-Fi yang sama.
      2. Di HP: Opsi pengembang → Debugging nirkabel → nyalakan → Sambungkan perangkat dengan kode QR.
      3. Klik tombol di bawah, lalu arahkan kamera HP ke kode QR.

      Menunggu HP memindai…

      Atau pakai kode 6 angka
      1. Di Debugging nirkabel ketuk Sambungkan perangkat dengan kode penyambungan.
      2. Alamatnya terdeteksi otomatis di bawah; tinggal isi kodenya.
      Sudah tersambung kabel? Pindah ke Wi-Fi

      HP dan laptop di Wi-Fi yang sama. Klik, lalu kabel boleh dicabut.

      1. Sambungkan Android dulu sekali lewat Wi-Fi (kode QR) atau kabel — syarat dari Android, bukan dari LinkDeck.
      2. Di HP nyalakan Tethering Bluetooth.
      3. Di laptop tekan Win + R, ketik control printers, klik kanan HP → Connect using → Access point.
      4. Klik tombol di bawah. Setelah itu Wi-Fi/kabel boleh diputus.

      Perlu diulang hanya kalau HP di-restart. Bluetooth ±1–2 Mbps: cocok untuk clipboard, notifikasi, dan tampilan ringan.

      Android terhubung

      Untuk desktop XFCE, terminal, suara Debian, satu mouse, dan folder sinkron. Memakai agen LinkDeck di Debian — terpisah dari adb, jadi bisa tersambung walau Android tidak.

      1. Colok kabel dengan Debugging USB aktif (lalu lintas Debian lewat jalur adb yang terenkripsi).
      2. Di terminal Debian jalankan linkdeck-start.
      3. Debian muncul di panel Debian dengan label Kabel → pilih → Hubungkan.
      1. HP dan laptop di Wi-Fi yang sama. Tidak perlu Debugging USB/nirkabel.
      2. Di terminal Debian jalankan linkdeck-start. Pastikan IP Wi-Fi yang tampil satu jaringan dengan laptop.
      3. Debian muncul otomatis di panel Debian → pilih → isi PIN & sandi sekali → Hubungkan.
      1. Di HP nyalakan Tethering Bluetooth; di laptop control printers → klik kanan HP → Connect using → Access point.
      2. Jalankan linkdeck-start. Debian muncul dengan label Bluetooth.
      3. Tidak muncul? Isi alamat manual dengan IP = Default Gateway dari ipconfig.
